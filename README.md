# Роман Бедин — личный сайт

Личное портфолио C++ backend-разработчика: знакомство, навыки, опыт, шесть проектов,
контакты и отдельная страница резюме. Сейчас — локальная версия для разработки.
Репозиторий публичный; размещение сайта в интернете пока не включено.

## Запуск

Нужен Python 3. Из папки проекта:

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

Открыть **http://127.0.0.1:5173/**. На macOS также можно дважды нажать
`Запустить_сайт.command`. Остановка — `Ctrl+C` в терминале.
Если порт занят предыдущим запуском, сначала остановите его. Изменения видны после
обновления страницы. Открывайте сайт через HTTP-сервер: ES-модули не загружаются
через `file://`.

## Где редактировать

| Файл | Содержание |
| --- | --- |
| `src/content.js` | Имя, роль, контакты, тексты, навыки, опыт и проекты |
| `index.html` | Структура главной и короткие заголовки разделов |
| `styles.css` | Цвета в `:root`, сетка, адаптивность и печать резюме |
| `app.js` | Отрисовка данных, меню, навигация и копирование email |
| `src/visuals.js` | Декоративные SVG-иллюстрации проектов |
| `resume.html` | Самостоятельное резюме; текст обновляется отдельно |
| `assets/images/alpine-dusk.webp` | Фотофон первого экрана |

На странице резюме кнопка «Сохранить в PDF» открывает системное окно печати,
где можно выбрать PDF. Готовый PDF в репозиторий не добавлен.

Сайт использует обычные HTML, CSS и JavaScript без сборки, npm и внешних runtime-зависимостей.
Изображение и иконки локальные; аналитика, трекеры и внешние шрифты не подключены.
Ссылки на проекты ведут в GitHub. Email и Telegram в публичной версии заменены
на `[вот тут мои данные]`; ссылки на эти контакты и их копирование отключены.
Контакты можно заполнить в `src/content.js` и отдельно в `resume.html`.

## Содержание и оформление

Структура и настроение вдохновлены [lavafrai.ru](https://lavafrai.ru): фотография
на первом экране, тёмное оформление и фиолетовые акценты. Код, тексты, иллюстрации
и фон подготовлены для этого проекта. Изображения и тексты автора референса
не использованы.

Содержание проверено по актуальному банку опыта владельца. Исходные резюме,
банк опыта и рабочие документы в этот репозиторий не входят. Стажировка в Яндексе
и практика в ИПУ отмечены отдельно; CampusJudge указан как развивающийся проект
с рабочей локальной версией, Go — как направление развития.

Фон создан встроенным imagegen и оптимизирован в WebP. Это сгенерированная
иллюстрация, а не фотография, снятая владельцем сайта. Его можно заменить своим снимком.

Prompt: “Original photorealistic alpine lake at blue hour, mountain silhouettes
and reflections, slate-blue and muted lavender dusk, wide 16:9 hero background,
no people, buildings or text”.

## Публикация позже

Для статического хостинга достаточно файлов сайта: `index.html`, `resume.html`,
`styles.css`, `app.js`, `src/` и `assets/`. Пути относительные, поэтому сайт можно
размещать как в корне домена, так и в подпапке GitHub Pages. Настройки Pages,
домен, CI и автоматическое развёртывание на этом этапе не добавлены.
